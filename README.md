# Satyabhan Singh

Official academic website of **Satyabhan Singh**, PhD Researcher at **IIT Bombay**.

## Research Areas

- Computational Chemistry
- Homogeneous Catalysis
- Density Functional Theory (DFT)
- Machine Learning for Chemistry
- Bayesian Optimization
- Nitrogen Reduction Reaction (N₂RR)

- React
- TypeScript
- Tailwind CSS
